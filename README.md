# Test Programmation Stage

## Installation

À la racine du projet, exécuter la commande suivante pour installer toutes les dépendances du projet (backend et frontend) :

```bash
npm run install:all
```

## Démarrer l'application

Pour démarrer le backend et le frontend en même temps, exécuter :

```bash
npm run dev
```

## Démarrer séparément

Pour démarrer uniquement le backend :

```bash
npm run dev:backend
```

Pour démarrer uniquement le frontend :

```bash
npm run dev:frontend
```

## Tests

Pour exécuter les tests du backend :

```bash
npm test
```

## Informations supplémentaires

Le développement de cette application m'a pris environ 8 heures. La base de données utilise SQLite3 : elle est stockée localement et les données restent persistantes entre les redémarrages de l'application donc pas besoin d'installation.
